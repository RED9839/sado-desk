# 사도 혼잣말 대본 — 작업 지시서

## 무엇을 하는 일인가

트릭컬 리바이브 사도들이 바탕화면에서 혼자 중얼거릴 말을 **미리 써 두는** 일입니다.
지금은 사도가 먼저 말을 걸 때마다 LLM을 부르는데, 그 탓에

- 답이 길어지고(120자 초과 24%), 회차가 갈수록 더 길어짐
- 말투가 무너짐(말투 뚜렷한 사도의 고유 어미 유지 54%)
- 화면을 못 보는데 본 척함
- VRAM 5.2GB · 답까지 0.6~2.5초

대본으로 바꾸면 이 넷이 전부 없어집니다. **만들 때 걸러낼 수 있기 때문**입니다.

## 지금 상태

```
data/self-talk.json    사도 138명 · 1,529줄 · 평균 11.1줄
목표                   사도당 14줄  (모자란 사도 137명 · 403줄)
```

**이미 있는 줄은 지워지지 않습니다.** 가져오기는 기본이 '합치기'라 새로 쓴 줄만 더해집니다.
(정말 갈아엎으려면 `--replace`)

## 해야 할 일

`out/ask-gaps/gap-01.txt … gap-18.txt` 에 모자란 사도만 묶어 둔 프롬프트가 있습니다.
사도마다 **몇 줄이 더 필요한지**와 **이미 쓴 줄(겹치면 안 되는 것)** 이 적혀 있습니다.

1. 프롬프트대로 문장을 씁니다.
2. 답을 `out/답-gap-NN.txt` 로 저장합니다.
3. `node tools/selftalk-import.js --multi out/답-gap-NN.txt`
4. 버려진 줄과 이유가 찍힙니다. 이유를 보고 다시 써서 2번으로 돌아갑니다.
5. `node tools/selftalk-gaps.js 14 --list` 가 비면 끝입니다.

마지막에 `node tools/selftalk-act.js` 로 동작을 붙입니다.

> 사도 전체를 처음부터 다시 쓰고 싶으면 `out/ask/batch-01.txt … batch-23.txt` 를 쓰세요.
> 사도당 14줄씩, 위키 자료가 다 들어 있습니다.

## 반드시 지킬 것

- **게임 대사 원문을 그대로 쓰지 않습니다.** 프롬프트에 실린 '실제 대사'는 어미를 보라고 준 것이지
  베끼라고 준 것이 아닙니다. 10자만 겹쳐도 `실제 대사를 베낌` 으로 걸러집니다.
- **사도 말투를 지킵니다.** 문장마다 그 사도의 어미여야 합니다.
- **화면 내용을 아는 척하지 않습니다.** 바탕화면·창·커서 같은 '자리'는 되지만 내용은 모릅니다.
- **게임·AI·과금 이야기를 하지 않습니다.**

## 프롬프트에 들어 있는 것

사도마다 이만큼이 적혀 있습니다. 골고루 쓰면 12~14줄이 겹치지 않습니다.

| | 어디서 |
|---|---|
| 실제 대사 10줄 | 나무위키 대사표 + 테마극장 자막 |
| 인물·말투·말버릇·화제·성격·하지 않는 것 | `data/bible.json` |
| **소개** | 위키 개요·인물 소개 |
| **성향 낱말** | 위키 모험회 생활 스킬 (오지랖·애교·집요함 …) |
| **음식 취향** | 위키 연회장 기록 — 좋아하는·싫어하는 음식과 그때의 반응 |

## 걸러지는 잣대 (tools/selftalk-lib.js)

| 검사 | 내용 |
|---|---|
| 말투 | 문장마다 그 사도의 말투. 허용 범위는 **실제 대사 분포**로 정해짐(136명 중 66명이 두 가지 이상 섞어 씀) |
| 말버릇 말투 | `~다비`·`~사와요`·`~입니닷` 같은 고유 어미를 가진 사도는 **한 문장 이상** 그 어미여야 함 |
| 어법 | 어미를 겹쳐 붙인 없는 말 차단 (`좋겠어요사와요` ×, `설렘니닷` × — `~닷`은 앞 글자 받침이 ㅂ일 때만) |
| 이름 오타 | `크리페 ≠ 크레페` 같은 것. 실제 대사에 나오는 낱말은 통과 |
| 길이 | 12~70자 · 두 문장 이하 |
| 금지 | 이모지·이모티콘·마크다운·대괄호 꼬리표·영어 낱말·화자 이름·쉼표로 끝나기 |
| 원문 대조 | 나무위키 전체 18자 · 그 사도의 실제 대사 10자 |
| 중복 | 앞 줄과 낱말 35% 이상 겹치거나 첫 두 낱말이 같으면 버림 |
| 호칭 | 교주를 엉뚱한 직함으로 부르면 버립니다(`목사님`·`박사님`·`고객님`…). 다른 사도를 부르는 건 통과 |
| 예외 | **스키아**는 말을 하지 않는 사도라 `짧은 소리 + (몸짓 설명)` 꼴만 받습니다 |

버려진 이유는 `VERBOSE=1` 을 붙이면 줄마다 나옵니다.

```
VERBOSE=1 node tools/selftalk-import.js --multi out/답-gap-01.txt
```

## 자동으로 돌리려면

`tools/build-selftalk.js` 가 같은 잣대를 쓰면서 모델을 부릅니다.

```
node tools/build-selftalk.js all 12                  # ollama (무료·무제한, 어법이 자주 깨짐)
npx electron tools/build-selftalk.js all 12 gemini   # 앱 설정의 Gemini 키 (어법이 훨씬 나음)
npx electron tools/build-selftalk.js all 12 openai   # OpenAI 호환 (base·키는 앱 설정)
```

이미 12줄을 채운 사도는 건너뜁니다(`--redo` 로 다시).

## 파일

| | |
|---|---|
| `data/self-talk.json` | 결과물. `{t: 문장, m: 감정, a: 동작}` |
| `tools/selftalk-lib.js` | 걸러내는 잣대 (여기만 고치면 전부 반영) |
| `tools/style-match.js` | 말투 판정 (13종) |
| `tools/selftalk-import.js` | 가져오기 |
| `tools/selftalk-gaps.js` | 모자란 사도 프롬프트 |
| `tools/selftalk-batch.js` | 전체 사도 프롬프트 |
| `tools/selftalk-act.js` | 문장 → 동작 배정 |
| `tools/build-reflines.py` | 실제 대사 5,090줄 추출 (`out/_ref-lines.json`, 로컬 전용) |
| `tools/build-hero-extra.py` | 위키에서 개요·연회장 음식·생활 스킬 추출 (`out/_hero-extra.json`, 로컬 전용) |
