# prototype/data/ 라이선스

이 폴더의 데이터 파일은 소스 코드(MIT)와 다른 라이선스를 따릅니다.

## 나무위키 유래 — CC BY-NC-SA 2.0 KR
아래 파일은 [나무위키 트릭컬 리바이브 문서](https://namu.wiki/w/트릭컬%20리바이브)들을 읽고 요약·재구성한 2차적 저작물이며,
원문과 같은 [크리에이티브 커먼즈 저작자표시-비영리-동일조건변경허락 2.0 대한민국](https://creativecommons.org/licenses/by-nc-sa/2.0/kr/) 라이선스로 배포합니다.
- `talk-ko.json` — 사도별 말투 프로필(어투·호칭·감탄사). 대사 원문은 담지 않습니다.
- `theaters.json` — 테마극장 제목·주연·줄거리. 줄거리는 공식 소개 문구를 걷어내고 우리가 직접 쓴 요약으로 바꿨습니다(v0.11.9). 위키 편집자 해설(`note`)과 이벤트 기간(`period`)은 원문 그대로였고 앱이 읽지도 않아 v0.11.10 에서 뺐습니다.
- `bible.json` — 사도 인물 사전(요약). 원문을 옮기지 않았습니다.
- `names-ko.json` — 사도·스킨 한글 이름표(영문 표기 대조).

## 게임 보이스 통계 — 원문 없음
- `talk-style.json`, `relations.json` — 게임 보이스를 받아써(STT) 어미 비율·감탄사·자주 쓰는 낱말·서로 부르는 말을 **세어 놓은 통계**만 담습니다. 대사 원문은 배포 파일에 넣지 않습니다.
- `talk-style.json`의 `written`·`tic` 항목은 테마극장 플레이 영상의 화면 글자를 OCR로 읽어 **어미 비율만** 센 것입니다. 대본 자체는 배포하지 않고 로컬에만 둡니다.
