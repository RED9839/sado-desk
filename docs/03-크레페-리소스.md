# 크레페 (Crepe) 리소스 조사

> 분석일: 2026-09-11 · 마스코트 캐릭터로 **크레페** 확정
> 샘플: `docs/samples/crepe/` (스탠딩 스프라이트시트·atlas·skel·아이콘·터치 보이스 1개)

---

## 1. 결론 먼저

- 크레페는 **로비 스탠딩 Spine** + **미니미(공용 스켈레톤의 Crepe 스킨)** 두 형태가 있음. SD 전투 스프라이트(`spine/ingame/hero/crepe`)는 없음(전투 유닛 아님 — 로비/하우징 캐릭터, `fx_crepe_cleanup`).
- 게임에서 돌아다니는(폴짝폴짝 뛰는) 크레페 = **미니미** (`spine/minimi/`). 로비 설정·스테이지 목록·정원·타워배틀·트릭다이스 슬롯 등에서 쓰이는 SD 사도. **이게 데스크탑 마스코트에 가장 잘 맞는 형태** (아래 1.1).
- 스탠딩은 상호작용 세트(쓰다듬기·간지럽히기·터치·표정·감정 6계열)가 풍부. **보이스 56종**.

### 1.1 미니미 (★ 마스코트 본체 후보)

| 항목 | 내용 |
|---|---|
| 경로 | `spine/minimi/minimi.skel` (공용 스켈레톤, Spine 4.1) + `minimi.atlas` + 텍스처 3장 `Minimi.png`(2048²), `Minimi_2.png`, `Minimi_3.png` |
| 구조 | **캐릭터당 그림 1장** (파츠 분해 없음). 스킨 `Mini_{이름}` 418개 — 사도 전원+스킨. 크레페: `Minimi_3.png` bounds `198,380,134,185` (atlas scale 0.5 → 원본 약 270×277 캔버스) |
| 본 | 극소수 (`root`, `Rotate_CT`, `Minimi`) → 애니는 **전부 이동/회전/스케일(스쿼시&스트레치) 변형** |
| 애니메이션 (45개) | `Idle1_1~2`, `Idle2_1~5`, `Idle3_1~7`, `Act1_1`~`Act6_1`, `Attack1_1~8`, `Spawn10`, `Throw1_1~19`, `Throw2_1`, `Throw3_1~7` |
| 효과음 | `audio/sfx/sfx_minimi_jump01`, `jump02` |
| 샘플 | `docs/samples/crepe/minimi_crepe.png` (134×185 추출), `minimi.skel.bin` |

**의미**: 미니미 애니가 "그림 1장 + 변형"이라서
1. Spine 런타임 없이도 **자바 AffineTransform만으로 재현 가능** (skel에서 키프레임 값을 읽어 오거나, 눈으로 보고 유사하게 튜닝).
2. 걷기는 없지만 **폴짝폴짝 점프 이동(Idle/Act/Throw 계열)** 이 게임 원본 느낌 그대로 나옴 → "걷기 대신 뛰어다니는" 마스코트로 컨셉 잡으면 문제 해소.
3. 그림 1장만 갈아끼우면 **사도 400명+ 전원 지원** → 루미의 "창작마당 캐릭터"와 대응, 나중에 확장이 공짜.
4. `Throw*` 계열 = 게임에서 미니미를 집어 던지는 연출 → 시메지 `Dragged/Thrown/Fall`에 그대로 매핑.

## 5. 이동(걷기) 해결 선택지

| 방법 | 설명 | 공수 | 품질 |
|---|---|---|---|
| **★ M. 미니미 점프 이동** | 미니미 그림 1장 + 스쿼시/스트레치/점프 변형. 게임 원본 연출 그대로. 걷기 대신 폴짝폴짝 (프로토타입 v0.1에서 구현) | 하~중 | 상 — 게임과 동일한 느낌 |
| **★ S. 스탠딩 `Move_1/2` 걷기** | 스탠딩 Spine에 걷기 애니가 있음(재확인). 스탠딩 하이브리드로 가면 걷기도 원본으로 해결 | 중 | 상 |
| **A. Spine 스켈레톤에 Walk 애니 추가** | 크레페 skel을 Spine 에디터(또는 JSON 변환 후 수작업)로 열어 다리 본에 걷기 키프레임 제작. 원본 파츠 그대로 사용 | 중 (Spine 에디터 라이선스 필요, 리깅 이해) | 상 — 원본과 동일 화풍 |
| **B. 스탠딩 Idle을 미끄러지듯 이동** | Idle_1 재생하며 x좌표만 이동(공중부양/미끄럼). 프로토타입용 | 하 | 하 — 어색함 |
| **C. SD 도트/일러스트 직접 제작** | 아이콘(252px)의 SD 비율 기준으로 192×192 걷기 3~4프레임 + 서기 + 앉기 손그림. 루미 방식 그대로 | 상 (그림) | 상, 저작권도 깨끗 |
| **D. 하이브리드** | 이동·벽타기 = 직접 그린 PNG 프레임(시메지 표준), 클릭/쓰다듬기 순간엔 Spine 스탠딩으로 전환 | 중상 (엔진에 Spine 렌더 추가) | 상 |

권장: **M(미니미 점프 이동)을 기본 이동으로**, 클릭/쓰다듬기 등 상호작용 순간은 스탠딩 Spine(D)으로 전환하는 하이브리드. 미니미는 그림 1장이라 배포용으로 직접 그린 SD 1장으로 교체하기도 가장 쉬움(저작권 대응).

### 시메지 행동 ↔ 미니미 애니 매핑 (초안)
| 시메지 | 미니미 |
|---|---|
| Stand | `Idle1_*` |
| Walk / Run | `Idle2_*`/`Act*` 중 점프 이동류 + 루트 x 이동 |
| Sit / 유휴 | `Idle3_*` (7종, 긴 유휴 연출로 추정) |
| Dragged | `Throw1_*` 앞부분(들림) |
| Thrown / Fall | `Throw1_*` 비행 ~ `Throw2_1`/`Throw3_*` 착지 |
| 소환(하나 더 부르기) | `Spawn10` |
| 알람 패닉 | `Attack1_*` 반복 |

## 6. 크레페 캐릭터 설정 (페르소나·대사 작성 시 참고)
- 메이드/청소 컨셉 → 마스코트 행동 아이디어: 창 타이틀바 **먼지떨이로 청소**, 바탕화면 아이콘 정리 시늉, 알람 = "청소 시간이에요!", 크레딧 드랍 대신 **먼지뭉치/쿠키 드랍**
- 성격 키워드·말투는 인게임 대사(위키) 확인 후 `persona.txt` 작성 — 루미 `persona.txt` 포맷([정체성]/[지식 범위]/[성격·화법]/[금지]) 재사용
