AI 대화

AI 서비스

사도 우클릭 → AI 대화 또는 Ctrl+Shift+Space로 대화창을 엽니다. 사도별 말투 프로필(호칭·어미·감탄사)을 AI에 전달해 그 사도처럼 답하고, 답변의 감정에 맞춰 표정과 음성을 재생합니다. 대화 내용은 이 PC와 선택한 AI 서비스에만 전송됩니다.
답변은 AI가 생성한 것으로 공식 대사가 아닙니다. Ollama가 아닌 서비스는 대화·캡처가 그 서버로 전송되고, API 키 요금은 사용자 부담입니다.
자세히 보기
  • AI 대화의 답변은 AI가 생성하며, 원작 설정과 다를 수 있습니다. 공식 대사가 아닙니다. 이 앱은 팬이 만든 비공식 프로그램으로 에피드게임즈와 관계가 없습니다.
  • 스토리 내용이 언급될 수 있습니다. 사도가 자신이 등장한 테마극장이나 메인 스토리의 일을 먼저 꺼낼 수 있습니다. 아직 보지 않은 이야기라면 결말을 듣게 될 수 있습니다.
  • Ollama가 아닌 서비스를 사용하면 대화 내용이 해당 서비스의 서버로 전송됩니다. 개인정보나 비밀번호는 입력하지 마세요. 대화를 PC 밖으로 보내지 않으려면 Ollama(로컬)를 사용해 주세요.
  • API 키는 사용자 본인의 것이며, 선택한 AI 서비스와 사용량에 따라 요금이 발생할 수 있습니다. API 키는 이 PC에 저장하며, 선택한 AI 서비스 인증에만 사용합니다. 앱에는 키가 들어 있지 않습니다.

Google Gemini

설치가 필요 없어 가장 간단합니다. Google AI Studio에 구글 계정으로 로그인해 "Create API key"를 누르고, 발급된 키를 아래에 붙여 넣어 저장해 주세요. 무료 등급의 한도는 모델과 시기에 따라 다르며 Google AI Studio에서 확인할 수 있습니다.

Ollama (로컬)

내 PC에서 실행되는 AI입니다. API 키와 요금이 없고 대화가 PC 밖으로 나가지 않습니다. 대신 모델 파일 5GB 안팎을 내려받아야 하고, 그래픽카드가 없으면 답변에 몇 초씩 걸립니다. 잘 모르겠다면 설치가 필요 없는 위의 Gemini를 권장합니다.
① Ollama 설치
설치 파일을 받아 실행하면 됩니다. 따로 켤 필요 없이 백그라운드에서 항상 실행됩니다. 설치가 끝나면 이 줄이 ✓로 바뀝니다.
② 한국어 모델 내려받기
아래 '내 PC' 줄의 권장 모델을 '내 PC에 맞추기'로 넣고 '내려받기'를 눌러 주세요. 한 번만 하면 됩니다.
자세히 보기 — 모델 비교 (실측) 아래 속도는 RTX 4080 기준이고, 괄호 안은 그래픽카드 없이 CPU만 쓸 때입니다.
· exaone3.5:2.4b 1.6GB — 가장 가볍습니다. 답 0.2초(1.0초). 다만 사도 고유 어미(~다비·~입니닷)를 자주 놓쳐요(재현 34%).
· exaone3.5:7.8b 4.8GB — 기본값. 답 0.5초(2.2초). 어미 재현 80%로 말투가 가장 낫습니다.
· qwen2.5:14b 9GB — 그래픽카드 메모리가 10GB 넘을 때. 답 0.8초(5.5초). 어미는 72%로 조금 낮지만 "이 게임 재밌어?" 같은 말에 사도 말투가 깨지는 일이 훨씬 적습니다.
말투 재현은 Gemini·Claude보다 낮게 측정됐습니다. 그래픽카드가 없거나 RAM이 8GB인 PC에서는 9GB 모델이 실행되지 않으므로 2.4b를 권장합니다.
