# 사도 데스크 (SadoDesk)

**트릭컬 리바이브** 사도를 윈도우 바탕화면에 살게 하는 데스크탑 마스코트. 비공식 팬 프로젝트입니다.

> **현재 상태: 배포 전.** 에피드게임즈에 2차 창작 가이드라인 적합 여부를 문의해 두었고, 답을 받은 뒤에 배포·안내할 계획입니다.
> 저장소는 검토하실 수 있게 공개해 두었을 뿐이며 커뮤니티에 게시하지 않았습니다.

## 무엇을 하나

| | |
|---|---|
| **바탕화면에 사도** | 게임 원본 Spine 동작 그대로. 폴짝 이동·점프·대기 동작, 작업표시줄 위에 겹쳐 그리기, 사도 위가 아닌 곳은 클릭이 아래 창으로 통과 |
| **형태 3종** | **미니미**(게임 로비의 작은 모습) · **스탠딩**(사도 상세 화면) · **전투 SD**(전투에서 쓰는 모습) |
| **여러 사도** | 사도마다 외형·형태·크기·행동을 따로. 놓아둔 모니터에 머물고, 끌어다 놓으면 그 모니터로 |
| **교감** | 쓰다듬기 · 볼 당기기 · 꿀밤 · 간지럽히기 · 들어 올려 던지기 — 각 동작에 맞는 게임 음성 |
| **표정 고정** | 기본 · 미소 · 분노 · 슬픔 · 행복 · 냠냠 · 삐짐 · 놀람 (우클릭 메뉴 → 표정) |
| **혼잣말** | 미리 써 둔 대본 6,700여 줄. 시간대·교감 상황에 맞춰 한마디. **AI 없이 동작** |
| **AI 대화** | 사도가 자기 말투로 대답 (선택 기능, 아래 참조) |
| **새 소식** | 공식 유튜브·네이버 게임 라운지에 새 글이 올라오면 **그 사도의 말투**로 말풍선 알림 |

> 사도 외형·동작·음성 등 게임 데이터는 **EPID Games**의 저작물이며 이 저장소와 설치 파일에는 들어 있지 않습니다.
> 앱을 처음 실행하면 **사용자 PC의 앱플레이어(뮤뮤·LD플레이어·블루스택)에 설치된 트릭컬 리바이브**에서 게임 데이터를 가져오는 화면이 뜹니다. 가져온 데이터는 본인 PC에서만 쓰고 재배포하지 마세요.

## 설치 / 실행

1. [Releases](../../releases)에서 `SadoDesk-Setup-x.y.z.exe`를 받아 설치합니다. 코드 서명이 없어 처음 실행할 때 SmartScreen 경고가 뜹니다 — **"추가 정보 → 실행"**. (다음 판부터는 앱 안에서 받아 설치하므로 이 경고가 뜨지 않습니다.)
2. 첫 실행 → **게임 데이터 가져오기** 창에서 앱플레이어를 고르고 "가져오기 시작". 미니미·효과음(필수), 스탠딩(2~5분), 로비 음성(5~10분), 전투 SD(선택). 저장 위치는 `%APPDATA%\사도 데스크\assets`.
**업데이트**: 새 버전이 나오면 알림이 뜨고, **앱 안에서 받아 설치**합니다 (트레이 메뉴 또는 설정 → 정보 → 업데이트). 받은 파일은 GitHub가 알려 주는 검사값(SHA-256)과 대조하며, 설치하는 동안 사도가 잠시 사라졌다가 새 버전으로 돌아옵니다. 설정과 게임 데이터는 그대로입니다.

3. 사도가 화면에 나타납니다. **우클릭 = 메뉴**, **트레이 아이콘 = 설정**. 다른 모니터에 두고 싶으면 끌어다 놓으면 그곳에 머뭅니다.

- 앱플레이어에 트릭컬 리바이브가 설치·실행된 적이 있어야 합니다(리소스가 기기에 내려받혀 있어야 함). 게임에서 **사도 상세 화면을 열어 본 사도만 스탠딩**이 있습니다.
- **지원 앱플레이어**: 뮤뮤 12(꺼져 있으면 자동 실행) · 뮤뮤 구버전 · LD플레이어(9/14) · 블루스택 5, 그 외 adb가 붙는 것. 앱플레이어를 켠 상태에서 "다시 검색".
- 블루스택은 설정 → 고급 → **Android 디버그 브리지(ADB)**, LD플레이어는 설정 → 기타 → **ADB 디버깅 '로컬 연결 열기'** 가 필요합니다(둘 다 기본 꺼짐. 꺼져 있으면 목록에 안내가 뜨고, LD는 버튼 하나로 켤 수 있음).
- LD와 블루스택은 같은 5555 포트를 써서 동시에 켜면 한쪽이 안 잡힐 수 있으니 가져올 앱플레이어만 켜세요. 자동 검색이 안 되면 adb.exe 경로나 포트(예 `5555`)를 직접 입력.
- 실제 스마트폰은 안드로이드 11 이상에서 adb로 앱 데이터를 읽을 수 없어 앱플레이어가 필요합니다.
- 윈도우 사용자 이름이 한글이면 adb가 그 경로에 파일을 못 만들어, 임시 폴더로 8.3 짧은 경로나 `C:\Users\Public\sadodesk-tmp`를 자동으로 씁니다.
- 앱플레이어의 adb가 구버전(블루스택 1.0.36)이면 첫 가져오기 때 구글 platform-tools adb(6MB)를 내려받아 씁니다(`%APPDATA%\사도 데스크\tools-cache`). 인터넷이 안 되면 앱플레이어 adb로 세트별 복사로 진행합니다.
- 다시 가져오기는 이미 있는 외형·음성을 건너뛰어 빠릅니다(첫 가져오기 약 1분 40초, 다시 가져오기 5초 — 스탠딩 498세트·음성 7,600개 기준).
- 게임 서버나 실행 중인 게임을 건드리지 않고, 앱플레이어 저장소의 파일을 adb로 복사만 합니다. 게임 파일은 암호화되지 않은 표준 Unity AssetBundle이라 보호장치를 해제하는 과정이 없습니다.
</details>

게임 이용약관상 데이터 추출 관련 조항은 직접 확인하시고 본인 책임으로 사용하세요. 이 도구는 치트·서버 우회·계정 관련 기능이 전혀 없습니다.

## AI 대화 (선택)

AI 없이도 사도는 대본으로 혼잣말을 합니다. **말을 걸어 대답을 듣고 싶을 때만** 아래 중 하나를 준비하세요. 모두 설정 → **AI 대화** 탭에서 합니다. 키는 이 PC에 저장되고(Windows 암호화를 쓸 수 있으면 암호화) 대화는 선택한 AI 서비스에만 전송됩니다.

**가장 쉬운 길 — Google Gemini** (설치할 것 없음)
[Google AI Studio](https://aistudio.google.com/apikey)에서 **Create API key** → 설정 → AI 대화 → Google Gemini 칸에 붙여 넣고 **저장**. 무료 등급의 한도는 모델·시기에 따라 다르며(AI Studio에서 확인) 마스코트 용도로는 대체로 넉넉합니다. 대화 내용은 Google 서버로 갑니다.

**PC 밖으로 안 내보내려면 — Ollama** (로컬)
키·요금이 없고 대화가 PC를 떠나지 않습니다. 대신 모델 5GB 안팎을 내려받고, 그래픽카드가 없으면 답이 몇 초씩 걸립니다.
1. [ollama.com/download](https://ollama.com/download)에서 설치 → 설정 탭을 다시 열면 ① 줄이 ✓ 로 바뀝니다.
2. **내 PC에 맞추기** → **내려받기** (그래픽카드 메모리에 맞춰 1.6GB / 4.8GB / 9GB 중 하나). 한 번만 하면 됩니다.

**유료** — Anthropic Claude API 키를 넣으면 말투 재현이 가장 좋습니다(실측 기준). OpenAI 호환 서비스(Groq·OpenRouter·LM Studio)도 연결됩니다.
'자동 선택'은 Gemini 키 → Anthropic 키 → Ollama(실행 중·모델 있음) → OpenAI 호환 키 순으로 준비된 첫 것을 씁니다.

**먼저 말 걸기**는 설정에서 끌 수 있고, **화면 보기**는 기본 꺼짐입니다. 켜면 **허용한 앱의 창**(예: Chrome, 게임)을 캡처해 선택한 AI 서비스로 보냅니다. 창 제목의 앱 이름으로 고르며, 같은 앱의 창이 여럿이면 그중 하나를 보냅니다. 허용한 앱의 창이 없으면 보내지 않고, 캡처 이미지는 PC에 저장하지 않습니다.

## 문제가 생겼을 때

[이슈](../../issues/new/choose)에 다음 셋을 붙여 주시면 대부분 한 번에 원인을 찾습니다.

1. **진단 정보** — 설정(트레이 아이콘) → 정보 → **진단 정보 복사** → 붙여 넣기. 버전·설치판 여부·모니터 구성·AI 상태가 한 덩이로 들어갑니다. API 키·대화 내용은 들어가지 않습니다.
2. **app.log** — 설정 → 정보 → **로그 열기**를 누르면 파일이 선택된 폴더가 열립니다. 그 파일을 이슈에 끌어다 놓으세요. 앱이 켜지지 않으면 `Win+R` → `%APPDATA%\사도 데스크` 에 있습니다. 2MB를 넘으면 `app.log.1`로 밀리므로 파일은 최대 둘입니다. API 키·대화 내용은 남지 않습니다.
3. **다시 일어나게 하는 방법** — 순서대로, 매번인지 가끔인지.

게임 데이터 가져오기가 안 되면 가져오기 창의 **추출 로그 열기**(`%APPDATA%\사도 데스크\extract.log`)도 함께 붙여 주세요.

## 개발

```
cd prototype
npm install
run.cmd                 # 개발 실행 (assets/ 가 있으면 그것을, 없으면 %APPDATA% 의 가져온 데이터를 사용)
npm test                # 순수 로직 88개 (Electron 불필요)
npm run test:flow       # 사용 흐름 — 대화 경쟁 · 가져오기 제어 · 설정 복구 · 손짓 전달 · 두 번째 실행 · 설명 접기 · 창 크기 기억 · AI 실패 복구
npm run pyruntime       # 설치판용 임베디드 Python(UnityPy·Pillow·opusenc) 준비 → pyruntime/ (약 66MB)
npm run dist            # 설치판 빌드 → dist/SadoDesk-Setup-<ver>.exe
```

- 추출기 단독 실행: `python tools/extract-all.py --out <폴더> --steps minimi,sfx,standing,voice` (Python 3.10+, `pip install UnityPy Pillow imageio-ffmpeg`)
- 상세 구조·조작·설정·디버그 플래그: [prototype/README.md](prototype/README.md)
- 분석·변경 기록: [docs/](docs/) — Little LUMI 분석, 트릭컬 클라이언트 리소스 분석, 음성 카탈로그(STT로 카테고리 실측), 버전 기록, [실사용 검증 체크리스트](docs/05-실사용-검증.md), [말투 재점검](docs/07-말투-재점검.md)

## 에피드게임즈 2차 창작 가이드라인과의 관계

[에피드게임즈 2차 창작 가이드라인(2025.03.04)](https://epidgames.oqupie.com/portal/2399/article/73315)을 다음과 같이 지키려 합니다.

- **게임 IP 원본을 복제·배포하지 않습니다.** 설치 파일에는 모델·텍스처·음성·대사 원문이 없습니다. 사용자가 자기 앱플레이어에 설치된 게임에서 개인 사용 목적으로 읽어 오며, 그 파일은 사용자 PC 밖으로 나가지 않습니다.
- **비영리.** 무료이며 광고·후원·유료 기능이 없고, 앞으로도 넣지 않습니다.
- **공식 콘텐츠로 오인되지 않도록** 앱 안과 문서 전체에 비공식 팬 프로젝트임을 표시하고, 회사·게임 로고를 쓰지 않습니다.
- **미공개 콘텐츠를 다루지 않습니다.** 가져오기 대상은 이미 출시된 사도 기준입니다.
- 게임 클라이언트를 수정하거나 보호장치(암호화)를 해제하거나 게임 서버와 통신하지 않습니다.

이 프로젝트는 EPID Games와 무관한 개인 팬 프로젝트입니다. **권리자(에피드게임즈)의 요청이 있으면 배포를 즉시 중단하고 요청에 따릅니다.** 문의: 저장소 이슈.
