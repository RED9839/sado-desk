# 사도 말투 재점검 — 게임 보이스 대본(STT) 기반

> 2026-09-12 · 도구: `tools/transcribe-scripts.py`(faster-whisper large-v3-turbo, RTX 4080 SUPER, 73분) → `tools/analyze-scripts.py` → `data/talk-style.json`
> 입력: 클라이언트 `audio/kor/voice/hero/`의 **스토리 보이스**(`_selective_*`: 메인 스토리 · 테마극장(pray, frozen, lightashes, queensheart, youraurora, silvershell, magicbread …) · 인연) 25,115줄 + **로비 대사**(호감도·터치·잡담·성장·보드 등) 12,839줄 = 37,954줄 / 138 폴더(사도 133명 매칭)

## 왜 다시 봤나
기존 말투 프로필(`talk-ko.json`)은 나무위키 로비 대사표(사도당 10~90줄)에서 뽑은 것. 스토리·테마극장 대사는 위키에 없어서, 게임 안 목소리 파일을 받아써 실제 대사로 검증했다.
STT 원문(3만 8천 줄)은 저장소에 넣지 않는다(게임 텍스트). 저장소에는 사도당 20줄 안팎의 **표본 + 통계**(`data/talk-style.json`, 245KB)만.

## 분석 방법
- 문장 어미를 규칙으로 분류: 해요체 / 합니다체 / 반말 / 명사형 / 고유 어미(다비·그마·사와요·닷·옵니다·노라/거라·하오). 한 단어 감탄("헉", "교주님?")과 끊긴 조각은 제외
- **교주에게 하는 말**(호감도·터치·잡담·성장 등 PLAYER_CATS)과 **스토리**(다른 사도와의 대화 → 반말이 섞임)를 분리. 그중 **교감 반응(touch/dutchrubend)** 은 확실히 교주를 향한 말이라 판정의 기준
- 호칭(교주/교주님/돈/언니 …) · 자칭 · 감탄사 · 특징 어휘(다른 사도 대비 8배 이상 자주 쓰는 명사) · 표본(8~45자, 지배 어미 문장 우선, 고유 어미 사도는 그 어미가 들린 문장만)

## 결과 — 반영한 것 (고신뢰: 로비 30문장↑ · 지배 어미 65%↑ · 교감 반응 어미와 일치)
- 말투: **네르** formal→polite("~요" 65%, 교감 반응도 해요체) · **네르(격노)** formal→polite · **사리** polite→casual(교감 반응 반말 100%)
- 호칭: **알레트·에슈르·파툴라·유미미** 교주→교주님(에슈르 교주님 27회) · **레비(졸업)** 교주님→교주
- 나머지 차이(아래 표 `≠`)는 반영하지 않음: 스토리에서 다른 사도에게 반말을 쓰거나(아멜리아·폴란·칸나 — 교주에겐 합니다체), 고유 어미가 STT에 덜 잡히는 경우(비비 "사와요"→"싸워요", 모모 "입니닷"→"입니다", 아일라 "그마"), 스노키처럼 혼잣말은 반말·돈(교주)에겐 합니다체인 경우

## AI 대화에 쓰는 것 (`ai.js buildSystem`)
위키 표본 6줄 + STT 표본 14줄, 교주에게 쓰는 어미 비율(교감 반응 기준), 감탄사, 특징 어휘("네르, 케이크, 반란군, 백성들…")를 시스템 프롬프트에 넣는다. 프로필 말투와 실측 비율이 다르면 "기본 말투는 X, 감탄·혼잣말엔 반말이 N% 섞임"으로 설명.
