# 사도 데스크 (SadoDesk)

**트릭컬 리바이브** 사도를 윈도우 바탕화면에 살게 하는 데스크탑 마스코트. 비공식 팬 프로젝트입니다.

- 게임 원본 Spine 동작을 그대로 재생 — 미니미(사도 139명 · 사복 279벌), 스탠딩(사도 상세 화면), 전투 SD
- 여러 사도를 동시에, 사도별 개별 설정. 사도는 놓아둔 모니터에 머물고(끌어서 옮김), 작업표시줄 위에 겹쳐 그리며, 다른 창 위에서 바로 터치
- **표정 고정**: 기본 · 미소 · 분노 · 슬픔 · 행복 · 냠냠 · 삐짐 · 놀람 — 스토리 표정 8종으로 서 있게 (우클릭 메뉴 → 표정)
- 형태 3종: **미니미**(게임 로비의 작은 모습) · **스탠딩**(사도 상세 화면의 모습) · **전투 SD**(전투에서 사용하는 모습 — 게임 데이터 가져오기에서 '전투 SD' 선택)
- **AI 대화**: 사도 우클릭 → AI 대화 (Ctrl+Shift+Space). 사도가 자기 말투로 대답하고 감정에 맞춰 표정·음성을 냅니다. 무료로 쓰려면 [Ollama](https://ollama.com/download)(로컬) 또는 [Google AI Studio](https://aistudio.google.com/apikey) 무료 키, 더 좋은 답을 원하면 Anthropic API 키(유료). 키는 이 PC에 저장되고(Windows 암호화를 쓸 수 있으면 암호화) 대화는 선택한 AI 서비스에만 전송됩니다. 가끔 사도가 먼저 말을 걸기도 해요(설정에서 끌 수 있음). AI 없이도 미리 써 둔 대본으로 혼잣말을 합니다. **화면 보기**를 켜면(기본 꺼짐) 사도가 내 화면을 보고 지금 하는 일에 반응합니다 — 스크린샷이 선택한 AI 제공자에게 전송되니 동의하고 켜세요
- 공식 유튜브·네이버 게임 라운지에 새 소식이 올라오면 **그 사도의 말투**로 말풍선 알림 (139명 말투 프로필, 사복별 차이 반영)

> 사도 외형·동작·음성 등 게임 데이터는 **EPID Games**의 저작물이며 이 저장소와 설치 파일에는 들어 있지 않습니다.
> 앱을 처음 실행하면 **사용자 PC의 앱플레이어(뮤뮤·LD플레이어·블루스택)에 설치된 트릭컬 리바이브**에서 게임 데이터를 가져오는 화면이 뜹니다. 가져온 데이터는 본인 PC에서만 쓰고 재배포하지 마세요.

## 설치 / 실행

1. [Releases](../../releases)에서 `SadoDesk-Setup-x.y.z.exe`를 받아 설치합니다. 코드 서명이 없어 SmartScreen 경고가 뜨면 "추가 정보 → 실행".
2. 첫 실행 → **게임 데이터 가져오기** 창:
   - 앱플레이어에 트릭컬 리바이브가 설치·실행된 적이 있어야 합니다 (리소스가 기기에 내려받혀 있어야 함). 사도 상세 화면을 열어본 사도만 스탠딩이 있습니다.
   - **지원 앱플레이어**: 뮤뮤 12(꺼져 있으면 자동 실행) · 뮤뮤 구버전 · LD플레이어(9/14, ldconsole 경유라 다른 앱플레이어와 포트가 겹쳐도 됨) · 블루스택 5, 그 외 adb가 붙는 것. 앱플레이어를 켠 상태에서 "다시 검색"하면 트릭컬 데이터가 있는 기기를 골라 줍니다. 블루스택은 설정 → 고급 → **Android 디버그 브리지(ADB)** 를 켜야 하고, LD플레이어는 설정 → 기타 → **ADB 디버깅 '로컬 연결 열기'** 가 필요합니다 (둘 다 기본은 꺼짐. 꺼져 있으면 목록에 안내가 뜨고, LD는 버튼 하나로 켤 수 있음). LD와 블루스택은 같은 5555 포트를 써서 동시에 켜면 한쪽이 안 잡힐 수 있으니 추출할 앱플레이어만 켜세요. 자동 검색이 안 되면 adb.exe 경로나 포트(예 `5555`)를 직접 입력.
   - 다시 가져오기는 이미 있는 외형·음성을 건너뛰어 빠릅니다 (전체 첫 가져오기 약 1분 40초, 다시 가져오기 5초 — 스탠딩 498세트·음성 7,600개 기준)
   - 실제 스마트폰은 안드로이드 11 이상에서 adb로 앱 데이터를 읽을 수 없어 앱플레이어가 필요합니다.
   - 윈도우 사용자 이름이 한글이면 adb가 그 경로에 파일을 못 만들어, 임시 폴더로 8.3 짧은 경로나 `C:\Users\Public\sadodesk-tmp`를 대신 씁니다 (자동).
   - 앱플레이어의 adb가 구버전(블루스택 1.0.36)이면 첫 가져오기 때 구글 platform-tools adb(6MB)를 내려받아 사용합니다 (`%APPDATA%\사도 데스크\tools-cache`). 인터넷이 안 되면 앱플레이어 adb로 세트별 복사로 진행합니다.
   - "가져오기 시작" — 미니미·효과음(필수), 스탠딩(2~5분), 로비 음성(5~10분), 전투 SD(선택). 게임 서버나 실행 중인 게임을 건드리지 않고, 앱플레이어 저장소의 파일을 adb로 복사만 합니다. 게임 파일은 암호화되지 않은 표준 Unity AssetBundle이라 보호장치를 해제하는 과정이 없습니다.
   - 저장 위치: `%APPDATA%\사도 데스크\assets`
3. 사도가 화면에 나타납니다. 우클릭 = 메뉴, 트레이 아이콘 = 설정. 다른 모니터에 두고 싶으면 마우스로 끌어다 놓으면 그곳에 머뭅니다.

게임 이용약관상 데이터 추출 관련 조항은 직접 확인하시고 본인 책임으로 사용하세요. 이 도구는 치트·서버 우회·계정 관련 기능이 전혀 없습니다.

## AI 대화 켜기 (선택)

AI 없이도 사도는 미리 써 둔 대본 6,700여 줄로 혼잣말을 합니다. **말을 걸어 대답을 듣고 싶을 때만** 아래 둘 중 하나를 준비하세요. 어느 쪽이든 설정 → **AI 대화** 탭에서 합니다.

### 가장 쉬운 길 — Google Gemini 무료 키 (설치할 것 없음)
1. [Google AI Studio](https://aistudio.google.com/apikey) 에 구글 계정으로 들어가 **Create API key** → 키를 복사합니다.
2. 설정 → AI 대화 → **Google Gemini** 칸에 붙여 넣고 **저장**. 끝입니다.

무료 등급의 한도는 모델과 시기에 따라 다르며(Google AI Studio에서 확인) 데스크탑 마스코트 용도로는 대체로 넉넉합니다. 대화 내용은 Google 서버로 갑니다.

### PC 밖으로 안 내보내고 싶다면 — Ollama (무료 · 로컬)
내 PC 에서 AI 가 돌아갑니다. 키·요금·한도가 없고 대화가 PC 를 떠나지 않습니다. 대신 **5GB 안팎을 내려받고**, 그래픽카드가 없으면 답이 몇 초씩 걸립니다.

1. **① Ollama 설치** — [ollama.com/download](https://ollama.com/download) 에서 Windows 설치 파일을 받아 실행합니다. 설치가 끝나면 따로 켤 것 없이 뒤에서 늘 돌아갑니다. 설정 → AI 대화 탭을 다시 열면 ① 줄이 ✓ 로 바뀝니다.
2. **② 모델 내려받기** — 같은 탭에서 **내 PC에 맞추기** 를 누르면 그래픽카드 메모리를 보고 맞는 모델 이름을 골라 줍니다(1.6GB / 4.8GB / 9GB). 그다음 **내려받기**. 한 번만 하면 됩니다.
3. AI 서비스를 '자동 선택'으로 두면 Gemini 키가 없을 때 Ollama 를 씁니다. Ollama 만 쓰고 싶으면 **Ollama — 로컬** 로 고정하세요.

말투 재현은 Gemini 쪽이 낫습니다(실측: Ollama 7.8b 어미 재현 80%, 사양·모델별 수치는 설정 탭에 적어 두었습니다).

### 화면 보기
사도가 내 화면을 보고 한마디 하는 기능은 **기본 꺼짐**이고, 켜면 **설정에서 허용한 앱의 창**(예: Chrome, 게임)을 캡처해 선택한 AI 서비스로 보냅니다. 창 제목의 앱 이름으로 고르며 같은 앱의 창이 여럿이면 그중 하나를 보냅니다. 허용한 앱의 창이 하나도 없으면 보내지 않습니다. 캡처 이미지는 PC에 저장하지 않습니다.

## 개발

```
cd prototype
npm install
run.cmd                 # 개발 실행 (assets/ 가 있으면 그것을, 없으면 %APPDATA% 의 추출본을 사용)
npm run pyruntime       # 설치판용 임베디드 Python(UnityPy·Pillow·opusenc) 준비 → pyruntime/ (약 66MB)
npm run dist            # 설치판 빌드 → dist/SadoDesk-Setup-<ver>.exe
```

- 추출기 단독 실행: `python tools/extract-all.py --out <폴더> --steps minimi,sfx,standing,voice` (Python 3.10+, `pip install UnityPy Pillow imageio-ffmpeg`)
- 상세 구조·조작·설정·디버그 플래그: [prototype/README.md](prototype/README.md)
- 분석·변경 기록: [docs/](docs/) — Little LUMI 분석, 트릭컬 클라이언트 리소스 분석, 보이스 카탈로그(STT로 카테고리 실측), 프로토타입 버전 기록 · [말투 재점검(스토리 보이스 STT)](docs/07-말투-재점검.md)

## 에피드게임즈 2차 창작 가이드라인과의 관계

이 프로젝트는 [에피드게임즈 2차 창작 가이드라인(2025.03.04)](https://epidgames.oqupie.com/portal/2399/article/73315)을 다음과 같이 지키려 합니다.

- **게임 IP 원본을 복제·배포하지 않습니다.** 설치 파일에는 모델·텍스처·음성·대사 원문이 없습니다. 사용자가 자기 앱플레이어에 설치된 게임에서 개인 사용 목적으로 읽어 오며, 그 파일은 사용자 PC 밖으로 나가지 않습니다.
- **비영리.** 무료이며 광고·후원·유료 기능이 없고, 앞으로도 넣지 않습니다.
- **공식 콘텐츠로 오인되지 않도록** 앱 안과 문서 전체에 비공식 팬 프로젝트임을 표시하고, 회사·게임 로고를 쓰지 않습니다.
- **미공개 콘텐츠를 다루지 않습니다.** 추출 대상은 이미 출시된 사도 목록 기준입니다.
- 게임 클라이언트를 수정하거나 보호장치(암호화)를 해제하거나 게임 서버와 통신하지 않습니다.

이 프로젝트는 EPID Games와 무관한 개인 팬 프로젝트입니다. **권리자(에피드게임즈)의 요청이 있으면 배포를 즉시 중단하고 요청에 따릅니다.** 문의: 저장소 이슈.
