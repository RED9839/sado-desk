# 실사용 검증 기록과 체크리스트

자동 테스트(단위 45 · 흐름 4 시나리오 · 첫 실행 7항목)가 못 덮는 세 영역 — 설치 전체 과정, 장시간·환경 변화,
실제 AI 서비스별 장애 — 를 사람이 확인하는 목록. 한 번 확인할 때마다 아래 표에 날짜·판·결과를 적는다.

## 1. 설치 전체 과정

| 단계 | 확인할 것 | 확인 방법 |
|---|---|---|
| 설치 마법사 | SmartScreen "추가 정보 → 실행" 뒤 마법사가 뜨고, 설치 폴더 선택·바탕화면 바로가기 체크가 보이는가 | `SadoDesk-Setup-x.y.z.exe` 를 그냥 실행 (무인 `/S` 아님) |
| 첫 실행 | 게임 데이터 없음 → '게임 데이터 가져오기' 창이 첫 화면으로, 화면 안에 뜨는가 | 설치 직후 자동 실행 또는 바로가기 |
| 앱플레이어 검색 | 켜 둔 앱플레이어가 목록에 잡히는가 (뮤뮤 12 는 꺼져 있어도 켜 주는가) | '다시 검색' |
| 가져오기 | 미니미·효과음(필수) → 스탠딩 → 음성 순으로 진행률이 오르고, 끝나면 사도가 나타나는가 | '가져오기 시작' |
| 다시 가져오기 | 이미 있는 것은 건너뛰어 빨리 끝나는가 | 설정 → 정보 → 게임 데이터 다시 가져오기 |
| 첫 조작 | 우클릭 메뉴가 뜨고, 외형 바꾸기·AI 대화·설정이 열리는가 | 사도 우클릭 |

자동으로 확인된 부분: 설치판을 **무인 설치(`/S`)** 한 뒤 **빈 프로필**로 띄워 뮤뮤 자동 검색·연결 → 미니미·효과음
가져오기 → 마스코트 시작까지(`--setup-test`, 약 1분). 마법사 화면 자체와 다른 앱플레이어·파이썬/adb 없는 PC 는 사람이 본다.

| 날짜 | 판 | PC/앱플레이어 | 결과 |
|---|---|---|---|
| 2026-09-19 | 0.24.8 | 개발 PC · 뮤뮤 12 (무인 설치·빈 프로필·자동) | 통과 — 검색·연결·가져오기·사도 등장 |

## 2. 장시간 · 환경 변화

| 항목 | 확인할 것 | 기대 |
|---|---|---|
| 장시간 | 몇 시간 켜 둔 뒤 메모리(작업 관리자 '사도 데스크' 합계)·핸들이 계속 오르지 않는가 | 30분 이후 평평 (측정: 90분 평균 566MB, 사도 3명) |
| 절전 복귀 | 잠자기 → 깨운 뒤 사도가 제자리에 있고 클릭·드래그가 되는가, 대화창·말풍선이 남아 있지 않은가 | 그대로 동작 |
| 모니터 해제 | 사도가 있던 모니터를 뽑으면 남은 모니터로 오는가, 다시 꽂으면 창이 그 모니터까지 덮는가 | 300ms 뒤 `applyGeometry` — 사도는 남은 모니터 바닥으로 |
| 배율 변경 | 디스플레이 배율(100→125%)을 바꾸면 사도 크기·바닥·히트 판정이 맞는가 | 창 재배치 후 정상 |
| 전체화면 게임 | 게임을 전체화면으로 → 사도가 숨고, 창 모드/알트탭으로 나오면 돌아오는가 | '전체화면 앱 위에서는 숨기기' 켬 기준 |
| 작업표시줄 이동 | 작업표시줄을 다른 변으로 옮기거나 숨김으로 바꾸면 바닥이 따라오는가 | 다음 기하 갱신 때 반영 |

| 날짜 | 판 | 항목 | 결과 |
|---|---|---|---|
| 2026-09-18 | 0.24.0+ | 장시간 90분 (win-unpacked, 사도 3명 대기) | 평균 566MB, 30분 뒤 평평, 핸들·스레드 고정 — 누수 없음 |

## 3. 실제 AI 서비스별 장애

가짜 OpenAI 호환 서버로 확인한 것: 스트림 중간 끊김 → 429 → 401 → 정상 순서에서 안내 문구·받은 조각 보존·입력
복구·기록(`aifail` 시나리오). 실제 서비스에서 확인한 것: Gemini 잘못된 키(실제 400), Ollama 죽은 포트, 없는 호스트.

| 서비스 | 확인할 것 | 방법 |
|---|---|---|
| Gemini | 무료 한도(429) 때 Lite 로 넘어가거나 잠시 뒤 재시도하는가, 안내가 뜨는가 | 짧은 시간에 여러 번 말 걸기 |
| Gemini | 응답이 중간에 끊겼을 때 한 번 재시도 뒤 완결 문장까지만 남는가 | 긴 답을 유도 (v0.22.2 에서 실측·고침) |
| Claude | 잘못된 키(401)·잔액 부족(400 credit)·과부하(529) 안내 | 키를 틀리게 저장 / 잔액 0 계정 |
| Ollama | 답 중에 Ollama 를 끄면 끊김 안내 뒤 입력이 열리는가, 다시 켜면 다음 턴이 되는가 | 작업 관리자에서 ollama 종료 |
| 공통 | 인터넷을 끊고 말 걸기 → "연결할 수 없습니다" · 다시 연결하면 정상 | Wi-Fi 끄기 |

| 날짜 | 판 | 서비스·상황 | 결과 |
|---|---|---|---|
| 2026-09-19 | 0.24.8+ | Gemini 잘못된 키 (실제 요청) | "API 키가 올바르지 않거나…" · 입력 복구 |
| 2026-09-19 | 0.24.8+ | Ollama 죽은 포트 · OpenAI 호환 없는 호스트 | 연결 불가 안내 · 입력 복구 |
| 2026-09-19 | 0.24.8+ | 가짜 서버: 끊김·429·401·90초 무응답 | 안내 · 조각 보존 · 입력 복구 · 다음 턴 정상 |
