# 세계관 규칙 — 대사가 어기면 안 되는 것

나무위키 `트릭컬 리바이브/설정` 을 우리가 쓰는 형태로 추린 표다. **사도 개인 설정(bible.json)이
아니라 "이 세상의 규칙"** 쪽이라, 개인 문서만 보고 쓰면 여기가 샌다.
기계 검사는 `prototype/tools/world-check.js` 가 맡고, AI 채팅 프롬프트에는 `ai.js` 의 `WORLD` 로 들어간다.

## 2. 알아 두면 대사가 살아나는 것

- **어리숙함은 설정이다.** 똑똑한 사도도 한두 군데가 어긋난다(다야가 유리와 다이아를 구분 못 하는 것처럼).
  세계수의 영향이 옅어지며 점점 심해지는 중이라는 서술까지 있다 — 그러니 '완벽한 전문가'로 쓰면 오히려 어긋난다.
- **생태가 지구와 다르다.** 고기·가죽이 나무에서 열리고 우유는 목장 우물에서 긷는다. 식물 중에 지성체가 있다.
- **마법은 근본이 없다.** 체계를 세우려는 쪽은 에슈르와 마녀뿐이고, 마력 회복에 제일 좋은 것은 민트다.
- **어사이드**는 5성 사도의 속마음이 실체화한 것. 영춘이 뽑아 주고, 교주에겐 친한 사도 것만 보인다.
- **빵주**는 엘리아스 바깥 탐험용 비공정. 차원문이 달려 있고 정박 후 일주일은 못 쓴다.
- **교주**는 예언된 인간이라 배척받지 않는다. 각 종족 수장보다 한 계단 위로 대우받는다.

# 2차 — 종족·지명·핵심 설정 문서까지 (v0.16.3)

처음엔 `트릭컬 리바이브/설정` 한 장만 봤다. 종족 문서 8개, 지명·조직, 엘드르·주말농장·엘다인·
여섯가지 보물·연표·콘텐츠까지 더 읽고 규칙을 늘렸다.

## 종족별로 틀리기 쉬운 것

| 종족 | 사는 곳 | 꼭 지킬 것 |
|---|---|---|
| **요정** | 에르피엔(요정 왕국, 중앙·세계수 주변) | 날개가 있어도 **날지 못한다**(죠안·각성 에르핀만 예외). 태어날 때부터 마법을 쓸 줄 알지만 갈고닦지 않는다. 설탕·빵이 주식이고 뿌리채소를 싫어한다. 사카린·민트초코·파인애플 피자는 배척 |

| **미스틱** | 불명 | 요미 하나뿐. 세계수가 아니라 **달**을 섬긴다. 종족 규모·거주지를 단정하면 안 된다 |

## 주말농장 — 죽음을 대신하는 화법

- 죽음·저승·천국·지옥이 전부 **주말농장**이다. 완곡어가 아니라 **그 말밖에 없어서 나오는 화법**이다 —
  돌려 말하는 티가 나면 틀린 것이다. 밝고 따뜻한 곳으로 여겨진다.
- 바다 쪽(글레이시아·모듬회 만)은 **주말어장**이고, 춥고 비린 고통스러운 곳으로 친다.
- 실제 효과: 자연사 없음, 부상·질병이 크게 약해짐(도끼에 맞아도 혹), 회복이 빠르다. 다만 굶고 아프고
  피는 난다. **마음의 상처는 지켜 주지 않는다.**

## 사도가 모르는 것 — 대사에 나오면 안 된다

세계수가 이미 죽었다는 것 · 겨우살이(가짜 세계수) · 쇠락의 원인 · 니펠과 농장의 주인 ·
영원살이의 정체와 최후 · 투구꽃 · 엘리아스의 의지 · 다른 차원(R41·흑뉴아·차원 소멸) ·
일곱 그루와 진명(영춘 동백·동동 버들) · 최초의 인간의 시대.
→ `world-check.js` 의 `스포일러`·`영원살이` 규칙이 잡는다.

# 3차 — 세계관 규칙으로 4,498줄을 다시 훑다 (v0.16.4)

규칙을 세웠으니 이제 대사를 규칙에 대고 읽었다. 사도마다 **세계관 규칙 12가지 + 그 사도의 종족 규칙 +
대사 전체**를 한 파일에 묶어(`out/worldcheck/<키>.md`) 여섯 갈래로 나눠 검토했다.
성격이 어울리는지는 보지 않았다 — 이번엔 세상의 규칙만.

**고친 줄 35.** 규칙별로:

| 규칙 | 고친 줄 |
|---|---|
| 죽음이 없다 | 바리에 `늙어 죽을지도` · 에르핀 `심심해 죽겠어` · 제이드 `목숨을 거는` · 쥬비 `죽여주게` · 힐데 `다칠 수도 없다`(→크게 다칠 일도) · 란 `벗이 살아 있었다면`(→곁에 있었다면) · 셰이디 `뼈도 못 추릴` |
| 유령은 잠이 없다 | 키샤·레테·바롱·베루의 `눈 뜨자마자` · 스피키 `눈이 스르르 감기네요오` · 스피키(메이드) `스피키였으면 잤겠지만` · 셀리네 `잠이 다 안 온다` |
| 종족 능력·입맛 | 아야(마녀) `아이스크림`→칡즙 · 에슈르(요정) `당근튀김`(마녀 음식)→설탕 도넛 · 비비(용족) `수은을 뿜었을`→흩뿌렸을 |
| 지구를 모른다 | 멜루나 `지구 세금` · 피코라 `인플루언서` · 레비 `버스비` · 나이아 `몸의 칠십 퍼센트` · 그윈 `별자리` · 셰럼 `인류 갈등` · 코미 `인간의 미식` · 슈팡 `내비게이션` |
| 지명·표기 | 슈로·우로스 `정령 호수`→**정령산 호수** · 샤샤 `소방 대장`→특별 소방 요정 · 아일라·에슈르(마도) `석류석 열매`→석류석(광물) · 실피르 `물귀신`→물 정령 · 스패럿 `술`→주스 |
| 기후 | 큐이 `겨울에도` · 오로라 `눈 덮인 언덕`→안개 내린 언덕 |
| 스포일러 | 아야 `영원살이 일곱 자매의 맏이` · 리뉴아(알바) `이 시공간에서도`·`다른 시간선에서 흘러온` (정체를 숨기던 시절이다) |

**반려한 지적 하나**: 쥬비가 "날 수 있어서 안 다쳤다비"라고 한 줄을 종족 규칙 위반으로 본 의견이 있었으나,
원작 대사가 `날아간다비~!`·`붕붕 날아오른다비`라 실제로 난다. 규칙은 "스스로 나는 **종족**은 용족뿐"이라는
뜻이지 개별 사도의 날개를 부정하지 않는다.

**검사기에 새로 박은 것**: 죽음 관용구(`죽겠`·`죽여주`·`목숨을 걸`·`늙어 죽`), 유령의 기상 표현
(`눈 뜨자마자`·`잠에서 깨`), 용족의 `뿜었`, 지명 `정령 호수`, 그리고 규칙 둘 —
**인간중심**(`인류`·`인간의 ~`)과 **지구교통**(버스·지하철·택시. `버스킹`은 제외).

끝난 뒤 `selftalk-audit.js` 0건, `world-check.js` 0건. 4,498줄 전부 통과다.
