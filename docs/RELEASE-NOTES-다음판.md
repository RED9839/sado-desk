## 사용자가 바로 느낄 것

**교감이 게임처럼 됩니다**
- 볼 당기기·쓰다듬기가 이제 **얼굴이 실제로 따라 늘어납니다**. 게임이 손가락 위치로 끌고 다니는 조작 본
  (`Character_Ball_Move`·`Character_Pat`)을 그대로 씁니다. 전에는 애니만 재생하고 본은 건드리지 않았습니다
- 몸을 잡고 **가로로 문지르면 간지럽히기**, 위아래로 끌면 들어올리기
- 살짝 톡 친 것과 실제로 당긴 것을 가릅니다. 전에는 볼에 손만 대도 "당기지 마!"가 나왔습니다

**대사가 훨씬 덜 반복됩니다**
- 클릭 대사가 사도에 따라 **1개에서 20개 넘게** 늘었습니다. 앞 카테고리에 파일이 하나라도 있으면
  거기서 멈추던 것을 고쳤습니다(벨라는 인사 1개뿐이라 늘 같은 말만 했습니다)
- 볼 당기기·쓰다듬기도 있는 대사를 다 씁니다(전에는 친밀 3단계 중 하나로 고정)

**AI 대화**
- 먼저 말 걸 때 같은 말풍선이 두 번 뜨던 것, 사도가 제 혼잣말에 대답하던 것을 고쳤습니다
- 화면 보기가 꺼져 있는데 "화면 보니 코딩하시네요" 하던 것을 막았습니다
- 말풍선에 파이썬 코드가 통째로 나오던 것을 막았습니다
- 답이 너무 길어지던 것을 줄였습니다(120자 초과 45% → 24%)
- 설정 → AI 대화에 **주의 문구**와 **모델을 메모리에 두는 시간**(게임할 때 VRAM 5.2GB를 비울 수 있습니다)

**새 소식**
- 깃허브에 새 판이 나오면 알려 줍니다. 버전만 비교하고 아무것도 보내지 않습니다

## 만드는 쪽 이야기

- 사도 138명 인물 사전에 말투 설계·상황별 반응·금지 사항을 더했습니다(`bible.json`)
- 테마극장 줄거리 69편을 **우리 글로 다시 썼습니다**. 위키 원문은 배포 데이터에서 전부 걷어냈습니다
- 사도 혼잣말 대본 1,500여 줄을 모으는 중입니다. 먼저 말 걸기를 LLM 대신 대본으로 바꾸기 위한 것입니다

## 낼 때 할 일

1. `prototype/package.json` 의 `version` 을 정하기 (지금 0.11.17 — 묶어서 낼 거면 0.12.0 도 좋습니다)
2. `cd prototype && npm run dist` → `prototype/dist/SadoDesk-Setup-<버전>.exe`
3. `git tag v<버전> && git push origin v<버전>`
4. 깃허브 릴리스 만들고 exe 첨부, 본문은 이 파일 내용
5. 이 파일 비우기
